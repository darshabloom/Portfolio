Currency Exchange

A graph-based currency exchange program that finds conversion paths and arbitrage opportunities.

Problem

Currency exchange can be represented as a graph, with currencies as vertices and rates as weighted edges.

Approach

I transformed exchange rates logarithmically and used Bellman–Ford to detect negative cycles representing arbitrage.

What it demonstrates

Graph modelling, algorithm selection, validation, path reconstruction and translating mathematical logic into working code.

Result

The program can identify arbitrage cycles, calculate profit and return useful exchange paths.
